# vscode

> Visual Studio Code keyboard shortcuts

- Open command palette:

`Ctrl + Shift + P`

- Quick file open:

`Ctrl + P`

- Toggle terminal:

`Ctrl + \``

- Split editor:

`Ctrl + \`

- Go to definition:

`F12`

- Find in files:

`Ctrl + Shift + F`

- Format document:

`Shift + Alt + F`

- Toggle comment:

`Ctrl + /`
