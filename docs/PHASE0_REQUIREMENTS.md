## 1. 沉浸式窗口默认行为

### 1.1 主窗口动作
- **打开沉浸窗口后**: 主窗口自动隐藏到系统托盘
- **关闭沉浸窗口后**: 主窗口从托盘恢复显示并聚焦

### 1.2 窗口形态
- **窗口类型**: 独立窗口（非覆盖模式）
- **默认大小**: 1200×800 (可调整)
- **默认位置**: 右下角贴边（预留 20px 边距）
- **窗口属性**:
  - 可拖拽
  - 可调整大小
  - 可置顶（默认关闭）
  - 半透明可选（默认不透明）

### 1.3 窗口状态持久化
保存以下状态到配置文件：
- 窗口位置 (x, y)
- 窗口大小 (width, height)
- 置顶状态 (always_on_top)
- 透明度 (opacity)
- 侧边栏可见性 (sidebar_visible)

### 2.2 核心组件

#### 2.2.1 顶部搜索栏
- **三色圆形按钮** (左侧)
  - 🟢 绿色: Commands only (#27AE60)
  - 🟠 橙色: Shortcuts only (#E67E22)
  - ⚪ 灰色: All (默认) (#95A5A6)
  - 当前选中: 实心圆
  - 未选中: 空心圆
  - 悬停显示提示文字

- **搜索输入框** (中间)
  - 实时搜索（输入即过滤）
  - 无需搜索按钮
  - Placeholder: "搜索所有收藏..."

- **关闭按钮** (右侧)
  - 点击关闭沉浸窗口

#### 2.2.2 左侧导航栏
- **贴边呼出**: 鼠标贴近左边缘（10px 内）自动展开
- **宽度**: 180-200px
- **内容**: 
  - 分组显示 (Commands / Shortcuts)
  - 显示每个分组的数量
  - 点击项目平滑滚动到对应卡片
  - 滚动同步高亮当前项
- **折叠按钮**: 底部 [◀] / [▶]
- **默认状态**: 折叠（保持沉浸感）

#### 2.2.3 内容区域
- **分组布局**:
  - 上半部分: Commands 分组
  - 下半部分: Shortcuts 分组
  - 分组标题带图标和数量

- **双列卡片布局**:
  - 一行两张卡片
  - CSS Grid 实现
  - 响应式（窄屏自动单列）

#### 2.2.4 卡片设计
- **内容不折叠**: 所有命令/快捷键直接显示
- **左边框颜色区分**:
  - Commands: 4px 绿色边框 (#27AE60)
  - Shortcuts: 4px 橙色边框 (#E67E22)
- **立体效果**:
  - 默认: 轻微阴影
  - 悬停: 上浮 + 加深阴影
  - 点击: 轻微缩小（按下感）
- **点击复制**: 点击卡片复制内容 + Toast 提示
- **字体**: 稍大字体（16px+）提升可读性

### 2.3 交互规则
1. **搜索即过滤**: 输入框输入时实时过滤，无需点击按钮
2. **渐进式披露**: 默认显示全部（All），需要时才过滤
3. **分组可折叠**: Commands 和 Shortcuts 分组可以折叠/展开
4. **命令不折叠**: 单个命令或快捷键的内容不折叠
5. **一次滚动看完**: 保持流畅性，无需点击切换

## 3. 数据范围

### 3.1 数据源
- **唯一数据源**: 现有 favorites 数据
- **不新增字段**: 不修改 favorites 存储格式
- **不做数据迁移**: 使用现有数据结构

### 3.2 数据读取
从 favorites 读取以下字段：
- `command`: 命令或快捷键内容
- `description`: 描述文本
- `scope::title`: 解析类型和页面标题
  - 格式: `"command::tar"` 或 `"shortcut::vim"`
  - 解析为: `{ scope: 'command', pageTitle: 'tar' }`

### 3.3 前端派生数据
以下数据在前端临时计算，不写回文件：
- `anchorId`: 用于锚点跳转 (如 `"card-command-tar"`)
- `groupKey`: 用于分组 (如 `"commands"` / `"shortcuts"`)
- `displayIcon`: 显示图标 (📦 / ⌨️)
- `borderColor`: 边框颜色 (#27AE60 / #E67E22)

### 3.4 数据流向
```
favorites (后端)
    ↓ get_favorites()
前端接收
    ↓ 解析 scope::title
    ↓ 派生 anchorId, groupKey 等
    ↓ 按 scope 分组
    ↓ 按 searchQuery 过滤
    ↓ 按 filterMode 过滤
渲染到 UI
```

**重要**: 沉浸窗口只读取数据，不修改 favorites

## 4. 技术约束

### 4.1 不新增第三方依赖
- 使用现有依赖: Vue 3, Tauri, markdown-it, vue-i18n
- 不引入新的 npm 包或 Rust crate
- 使用原生 CSS（不引入 UI 框架）

### 4.2 代码组织
- 新增组件放在 `frontend/tealdeer-widget/src/components/`
- 新增工具函数放在 `frontend/tealdeer-widget/src/utils/`
- 新增后端模块放在 `frontend/tealdeer-widget/src-tauri/src/backend/`
- 样式可内联在组件中（scoped）

### 4.3 兼容性
- 主要支持: Linux (Arch Linux)
- 次要支持: macOS, Windows (尽力而为)
- 浏览器: 基于 WebView (Tauri)
