#### 1. Tab 切换平滑过渡 ⭐⭐⭐⭐⭐

  ```css
    to { opacity: 1; transform: translateY(0); }
  }
  ```
**效果**：内容从下方淡入，更流畅自然
**成本**：0 字节（纯 CSS）

### 二、交互优化（高价值功能）

#### 6. 全局快捷键支持 ⭐⭐⭐⭐⭐
**当前问题**：只有 Ctrl+Alt+T 全局热键，应用内无快捷键
**优化方案**：
- `Ctrl+K` 或 `/`：聚焦搜索框
- `Ctrl+Enter`：执行搜索

- `Esc`：清空输入 / 关闭建议

```javascript
window.addEventListener('keydown', (e) => {
  if (e.ctrlKey && e.key === 'k') {
    e.preventDefault();
    commandInputRef.value?.focus();
  }
  // ... 其他快捷键
});
```
**效果**：键盘流操作，效率翻倍
**成本**：~80 行 JS，<1KB
