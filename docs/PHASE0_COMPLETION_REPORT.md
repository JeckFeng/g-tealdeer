## 完成的任务

### 1. 确认沉浸式窗口默认行为 ✅

#### 主窗口动作
- **打开沉浸窗口后**: 主窗口自动隐藏到系统托盘
- **关闭沉浸窗口后**: 主窗口从托盘恢复显示并聚焦

#### 窗口形态
- **窗口类型**: 独立窗口（非覆盖模式）
- **默认大小**: 1200×800 (可调整)
- **默认位置**: 右下角贴边（预留 20px 边距）
- **窗口属性**: 可拖拽、可调整大小、可置顶（默认关闭）、半透明可选（默认不透明）

#### 窗口状态持久化
保存以下状态到配置文件：
- 窗口位置 (x, y)
- 窗口大小 (width, height)
- 置顶状态 (always_on_top)
- 透明度 (opacity)
- 侧边栏可见性 (sidebar_visible)

### 2. 确认 UI 样式基线 ✅

#### 核心组件
1. **顶部搜索栏**
   - 三色圆形按钮（绿色/橙色/灰色）
   - 实时搜索输入框（输入即过滤）
   - 关闭按钮

2. **左侧导航栏**
   - 贴边呼出（鼠标贴近左边缘 10px 内自动展开）
   - 宽度 180-200px
   - 分组显示 + 数量统计
   - 点击平滑滚动 + 滚动同步高亮
   - 默认折叠（保持沉浸感）

3. **内容区域**
   - 分组布局（Commands 上，Shortcuts 下）
   - 双列卡片布局（CSS Grid）
   - 响应式（窄屏自动单列）

4. **卡片设计**
   - 内容不折叠（所有命令/快捷键直接显示）
   - 左边框颜色区分（Commands 绿色 #27AE60，Shortcuts 橙色 #E67E22）
   - 立体效果（悬停上浮 + 加深阴影）
   - 点击复制 + Toast 提示
   - 稍大字体（16px+）

#### 交互规则
1. 搜索即过滤（实时，无需按钮）
2. 渐进式披露（默认显示全部）
3. 分组可折叠（Commands 和 Shortcuts）
4. 命令不折叠（单个命令/快捷键内容不折叠）
5. 一次滚动看完（保持流畅性）

### 3. 确认数据范围 ✅

#### 数据源
- **唯一数据源**: 现有 favorites 数据
- **不新增字段**: 不修改 favorites 存储格式
- **不做数据迁移**: 使用现有数据结构

#### 数据读取
从 favorites 读取：
- `command`: 命令或快捷键内容
- `description`: 描述文本
- `scope::title`: 解析类型和页面标题（如 `"command::tar"` → `{ scope: 'command', pageTitle: 'tar' }`）

#### 前端派生数据
以下数据在前端临时计算，不写回文件：
- `anchorId`: 用于锚点跳转
- `groupKey`: 用于分组
- `displayIcon`: 显示图标
- `borderColor`: 边框颜色

**重要**: 沉浸窗口只读取数据，不修改 favorites

| 导航栏 | 贴边呼出 | 默认隐藏，需要时才显示 |
| 卡片内容 | 不折叠 | 一眼看到所有信息 |
| 数据范围 | 只读 favorites | 不修改存储格式，降低风险 |
